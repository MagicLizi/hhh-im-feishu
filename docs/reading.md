# 公开 API 的阅读能力

`POST /im/v1/messages/read_status` 逐条查询本账号是否读过消息，会话与话题均使用确切消息编号；只接受明确的 `is_read=true`，缺失、无效编号和错误保持未知。没有连续水位，不以未读数或最新消息猜测。公开接口没有本人标已读操作，因此不声明写回，也不借用客户端私有接口。

`GET /im/v1/messages/:message_id/read_users` 支持用户授权查询近七天内本人发送的消息，包括话题回复。查询前读取消息确认发送者、会话与话题根；普通会话范围不接收独立回复，话题范围只接受对应根或其回复。接口未提供可靠的未读名单与总人数，首屏完整才可给已读人数，后续名单按真实分页查询。查询失败不能当成零人已读。

2026-10-29 使用借用的有效用户授权做只读核对：一条约 6.77 天的本人话题回复返回 `items=[]`、`has_more=false`；另一条约 22.24 天的本人话题回复返回 HTTP 400 / 230033，明确限七天。没有刷新借用授权、发送消息或记录正文。这个样本确认话题能力与超期边界，不代表非零名单或真实宿主界面已经验收；宿主验收另记任务报告。

官方资料：[消息阅读状态](https://github.com/larksuite/cli/blob/main/skills/lark-im/references/lark-im-message-read-status.md)、[查询消息已读信息](https://open.feishu.cn/document/server-docs/im-v1/message/read_users)。回归覆盖真实范围校验、错误范围不请求名单、超期回执保持未知；会话的原有权限、分页和人数测试继续保留。
